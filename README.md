# MySQL Assignment 1 – DDL Commands & Constraints

##  Project Overview

This repository contains my MySQL Assignment 1, focused on **DDL (Data Definition Language) commands and database constraints**.

The assignment demonstrates how to create and manage databases and tables, define constraints, modify table structures, rename tables, truncate records, and drop database objects using MySQL Workbench.

##  Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

##  Topics Covered

### 1. Database Recreation
- DROP DATABASE
- CREATE DATABASE
- USE DATABASE

### 2. Departments Table
- PRIMARY KEY
- NOT NULL
- UNIQUE

### 3. Locations Table
- PRIMARY KEY
- AUTO_INCREMENT
- NOT NULL
- UNIQUE

### 4. Employees Table
- PRIMARY KEY
- AUTO_INCREMENT
- NOT NULL
- ENUM
- CHECK
- DEFAULT
- FOREIGN KEY

### 5. Table Alteration (ALTER)
- ADD a new column
- MODIFY column datatype
- DROP a column
- RENAME a column

### 6. Table Renaming (RENAME)
- Rename Departments table
- Rename Locations table

### 7. Table Truncation (TRUNCATE)
- Remove all records from a table while retaining its structure.

### 8. Database & Table Dropping (DROP)
- DROP TABLE
- DROP DATABASE
